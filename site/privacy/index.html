Privacy Policy

This notice describes the Stock Due Diligence website and the research-only plugin package in version 1.0.1. It must be reviewed if the implementation, hosting, or data practices change.

1. What this project does

The plugin is a set of research instructions and supporting documents. In version 1.0.1, it does not provide its own payment processor, user account system, or dedicated backend service for collecting stock research prompts.

2. Information you provide to ChatGPT

When you use ChatGPT, the prompts and content you submit are handled by the ChatGPT service under the applicable OpenAI terms and privacy notices and your account settings. Review those notices for how OpenAI processes information. Do not submit brokerage credentials, passwords, account numbers, or other sensitive information unless you have independently determined it is appropriate.

3. Website hosting and support

When you visit this static website, the hosting provider may process technical request data such as IP address, browser information, and access logs as part of operating and securing the site. The actual logs and retention depend on the hosting and DNS providers configured by the publisher. If you open a GitHub issue, information you post is processed by GitHub and may be publicly visible.

4. Data sharing and retention

This project does not intentionally collect stock prompts through a separate plugin backend in version 1.0.1. Website hosting, GitHub, DNS, and ChatGPT may process data under their own terms and configurations. Do not assume that data submitted to third-party services is deleted when you close this website.

5. Security

Use care when sharing information online. The publisher cannot guarantee the security or availability of third-party services. Report a privacy or security concern through the support page; avoid placing sensitive details in public issues.

6. Children

This project is not designed specifically for children. Do not use it to submit children's personal information.

7. Changes and contact

This policy must be updated when material data practices change, including if commerce, user accounts, analytics, or a backend service is introduced. For questions, use the support page.
