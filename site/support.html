Help and support

How can we help?

For questions, bug reports, corrections, or feature requests about Stock Due Diligence, open a GitHub issue in the public project repository.

Contact support / report an issue

Please do not post passwords, account numbers, private brokerage records, payment information, or other sensitive personal data in a public issue.

When reporting a problem

  • Describe the feature or workflow and what you expected.
  • Include the plugin version and a minimal reproducible example.
  • Remove personal or confidential information from screenshots and logs.
  • For a source correction, include the public source URL and relevant date.
